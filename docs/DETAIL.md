# 会话管理

左侧边栏插件。点击图标打开，按工作区分组管理会话。

## 表格

- 按工作区分组，名称下方显示工作区目录。
- 列包括：选择、标题、状态、创建时间、删除时间（仅回收站）、文件大小、会话路径、工作区详情、操作。
- 时间显示到秒；行高固定 3 行，内容过多时表格内部滚动。
- 表头居中，表体靠左，操作列居中并固定在右侧。
- 工作区详情一行一个显示会话涉及的顶层目录/文件，目录名以 `/` 结尾。
- 空表格居中显示「会话列表是空的」或「回收站是空的」。

## 批量操作

- 勾选行首复选框后，表格左上方按钮显示选中数量。
- 主界面「删除」：把选中会话移入回收站。
- 回收站「还原」：放回原路径并重新挂回工作区；原工作区不存在时放入默认工作区。
- 回收站「删除」：打开确认弹窗，输入 `DELETE` 后点「确认」才会彻底删除；「取消」只关闭弹窗。

## 详情

点击「详情」或双击行打开。按工作区、会话 ID、标题、状态、时间、大小、路径、工作区详情的顺序显示完整内容；每行最小 3 行高度，超出时自动换行。

## 注意事项

- 有运行中任务的会话不能删除。
- 删除时会话数据移入插件目录的 `trash/<会话ID>/`，并记录原工作区、路径、删除时间和详情元数据。
- 回收站会话会从客户端会话列表过滤，避免出现「未分组」；不使用归档状态。
